# ค่าปรับเกิน 10% ชอบด้วยกฎหมาย! และสิทธิได้รับเงินค่างานเมื่อถูกบอกเลิกสัญญา (คำพิพากษาศาลปกครองสูงสุดที่ อ. 122/2564)

เมื่อผู้รับจ้างทำงานล่าช้าจนค่าปรับพุ่งสูง หลายคนเข้าใจผิดว่าหน่วยงานรัฐ *ต้อง* บอกเลิกสัญญาเมื่อค่าปรับเกิน 10% และค่าปรับจะหยุดอยู่แค่นั้น แต่ความจริงแล้ว **ระเบียบพัสดุฯ ข้อ 138 ไม่ใช่เพดานค่าปรับ** และหน่วยงานสามารถปรับเกิน 10% ได้หากมีเหตุผลสมควร คดีนี้เป็นตัวอย่างที่ดีที่ชี้ให้เห็นถึงอำนาจในการปรับ และสิทธิของผู้รับจ้างที่จะได้รับเงินค่างานที่ทำไปแล้วแม้จะถูกบอกเลิกสัญญาก็ตาม

## สรุปข้อเท็จจริง
ห้างหุ้นส่วนจำกัด (ผู้ฟ้องคดี) ทำสัญญาก่อสร้างกับอำเภอ (ผู้ถูกฟ้องคดี) วงเงิน 2,999,000 บาท กำหนดแล้วเสร็จภายใน 120 วัน แต่ผู้รับจ้างประสบปัญหาขาดแคลนแรงงานจึงทำงานล่าช้า ได้รับการขยายเวลาสัญญาออกไปอีก 120 วัน แต่ก็ยังทำไม่เสร็จ (เนื้องานคืบหน้าประมาณ 30%)

จนกระทั่งค่าปรับสะสมจำนวน 127 วัน เป็นเงิน 380,873 บาท (คิดเป็น **12.7%** ของมูลค่าสัญญา) อำเภอจึงบอกเลิกสัญญา ริบหลักประกัน (149,950 บาท) และแจ้งเวียนเป็นผู้ทิ้งงาน ผู้รับจ้างจึงฟ้องคดี โดยโต้แย้งว่าค่าปรับไม่ควรเกิน 10% และขอให้ชดใช้ค่าก่อสร้างที่ทำไปแล้ว

## ประเด็นข้อกฎหมายและคำวินิจฉัย

### 1. ค่าปรับเกิน 10% ชอบด้วยกฎหมายหรือไม่?
ผู้รับจ้างอ้างระเบียบสำนักนายกรัฐมนตรีว่าด้วยการพัสดุฯ ข้อ 138 ที่ระบุว่า *"หากจำนวนเงินค่าปรับจะเกินร้อยละสิบ... ให้ส่วนราชการพิจารณาดำเนินการบอกเลิกสัญญา"* โดยเข้าใจว่านี่คือ "เพดาน" ค่าปรับที่จะเรียกเก็บได้

**ศาลปกครองสูงสุดวินิจฉัยว่า:**
*   **ระเบียบฯ มีไว้เพื่อประโยชน์ของราชการ:** ข้อกำหนดให้พิจารณาบอกเลิกสัญญาเมื่อค่าปรับเกิน 10% มีเจตนาเพื่อให้หน่วยงานรัฐบริหารสัญญาไม่ให้เกิดความล่าช้าจนเสียหายเกินเยียวยา **"มิได้มีความหมายว่า จำนวนค่าปรับ... จะต้องจำกัดไว้ไม่ให้เกินจำนวนร้อยละสิบ... เท่านั้น"**
*   **ค่าปรับคือมาตรการลงโทษ:** เพื่อให้คู่สัญญาเคารพสัญญา หากผู้รับจ้างยังทำงานไม่เสร็จและหน่วยงานยังไม่บอกเลิกสัญญา ค่าปรับก็เดินต่อไปได้
*   **12.7% ไม่สูงเกินส่วน:** ศาลมองว่าค่าปรับ 12.7% ในคดีนี้สมเหตุสมผลกับความเสียหายจากการที่งานล่าช้าและต้องหาผู้รับจ้างใหม่ จึงพิพากษาให้หน่วยงานมีสิทธิเรียกค่าปรับเต็มจำนวน (380,873 บาท)

### 2. งานไม่เสร็จ แต่มี "ประโยชน์" ต้องจ่ายเงินหรือไม่?
เมื่อบอกเลิกสัญญาแล้ว คู่สัญญาต้องกลับคืนสู่ฐานะเดิม (ป.พ.พ. มาตรา 391) แต่เนื้องานก่อสร้าง (ฐานราก อาคาร ฯลฯ) เป็นสิ่งที่คืนไม่ได้โดยสภาพ และหน่วยงานได้ใช้ประโยชน์จากงานนั้น (โดยให้ผู้รับจ้างรายใหม่มาทำต่อ)

**ศาลปกครองสูงสุดวินิจฉัยว่า:**
*   **ต้องชดใช้คืนเงินตามค่างานจริง:** หน่วยงานต้องจ่ายเงินชดเชยค่าผลงานที่ผู้รับจ้างทำไว้ แม้จะทำไม่เสร็จ
*   **การคำนวณมูลค่า:** ในคดีนี้ ผู้รับจ้างทำอาคารศูนย์เรียนรู้ (24.48%) และห้องน้ำ (55.05%) รวมเป็นมูลค่างาน **340,855 บาท** (ศาลใช้ตัวเลขจากการประมาณราคาจริง ไม่ใช่ % งวดงานตามสัญญา)

### 3. การหักกลบลบหนี้ (Offsetting)
แม้ผู้รับจ้างจะมีสิทธิได้รับค่างาน แต่ก็มีหนี้ค่าปรับที่ต้องชำระ ศาลจึงนำมาหักกลบกัน ดังนี้:

| รายการ | จำนวนเงิน (บาท) | สถานะ |
| :--- | :--- | :--- |
| **(1) ค่างานที่ทำได้** | **+ 340,855** | (รัฐต้องจ่าย) |
| **(2) ค่าปรับ** (12.7%) | **- 380,873** | (ผู้รับจ้างต้องจ่าย) |
| **(3) เงินประกันซองที่ริบไว้** | **+ 149,950** | (ถือเป็นเงินสดที่รัฐยึดถือไว้แล้ว นำมาหักหนี้ค่าปรับได้) |
| **รวมสุทธิ** | **+ 109,932** | **(รัฐต้องคืนเงินให้ผู้รับจ้าง)** |

**สรุป:**
*   ค่างาน (340,855) น้อยกว่าค่าปรับ (380,873) -> โดยปกติผู้รับจ้างต้องจ่ายเพิ่ม
*   แต่เนื่องจากรัฐริบเงินประกันไว้แล้ว (149,950) เมื่อนำมารวมคำนวณเสมือนเป็นเครดิต
*   **ผลลัพธ์:** (340,855 - 380,873) + 149,950 = **109,932 บาท**
*   ศาลพิพากษาให้หน่วยงาน **คืนเงิน 109,932 บาท** แก่ผู้รับจ้าง

## บทเรียนสำหรับผู้บริหารสัญญา
1.  **อย่าชะล่าใจเรื่องค่าปรับ:** การที่ค่าปรับเดินเกิน 10% ไม่ได้แปลว่าท่านจะหลุดพ้นความรับผิดชอบ หรือรัฐ "ต้อง" หยุดปรับ รัฐสามารถปรับต่อได้จนกว่าจะบอกเลิกสัญญา
2.  **งานที่ทำไปแล้วมีค่า:** หากถูกบอกเลิกสัญญา อย่าลืมรวบรวมหลักฐานเนื้องานที่ทำเสร็จและเป็นประโยชน์ (เช่น งานโครงสร้าง) เพื่อเรียกร้องค่าตอบแทนตามจริง
3.  **เงินประกันช่วยบรรเทาหนี้:** เงินสดหรือหลักประกันที่วางไว้ หากถูกริบหรือยึด สามารถนำมาขอหักกลบกับค่าปรับได้ในชั้นศาล เพื่อลดภาระหนี้สิน
