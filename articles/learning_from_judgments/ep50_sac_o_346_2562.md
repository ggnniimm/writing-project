# EP.50 อนุมัติตามรายงาน... แล้วโครงการพัง ผู้บริหารต้องรับผิดเสมอหรือ? (อ. ๓๔๖-๓๔๗/๒๕๖๒)

ท่านผู้บริหารหลายท่านคงกังวลว่า เมื่ออนุมัติเบิกจ่ายโครงการไปแล้วตามรายงานของเจ้าหน้าที่ แต่ภายหลังพบว่าโครงการมีปัญหา จะต้องรับผิดชดใช้ค่าเสียหายหรือไม่? วันนี้ "เรียนรู้จากคำพิพากษา" จะพาไปดูคดีจริงที่ศาลปกครองสูงสุดตอบคำถามนี้อย่างชัดเจนครับ

---

## 🏗️ เรื่องราว (The Story)

1.  **โครงการ:** เทศบาลตำบลบ้านแปะ (เดิมคือองค์การบริหารส่วนตำบล) อนุมัติโครงการก่อสร้าง**ตอม่อสะพาน**บ้านบนนา หมู่ที่ 14 ตำบลบ้านแปะ จังหวัดเชียงใหม่ ด้วยงบประมาณ 258,000 บาท โดยมีวัตถุประสงค์เพื่อสร้างตอม่อให้พร้อมสำหรับนำไม้พื้นสะพานเดิมมาวางพาดเป็นสะพานชั่วคราว (เนื่องจากงบประมาณไม่พอที่จะสร้างสะพานทั้งหมดในครั้งเดียว)

2.  **ขั้นตอนการอนุมัติ:** นายอนุชา ปัญญา อดีตนายกฯ ได้อนุมัติเบิกจ่ายเงินตามรายงานของ:
    *   คณะกรรมการตรวจการจ้าง → รายงานว่า "งานเสร็จเรียบร้อย ถูกต้องตามสัญญา"
    *   หัวหน้าเจ้าหน้าที่พัสดุ → เห็นควรเบิกจ่าย
    *   หัวหน้าส่วนการคลัง → เห็นควรอนุมัติ
    *   ปลัด อบต. → เห็นควรอนุมัติ

3.  **ปัญหา:** ต่อมามีชาวบ้านร้องเรียนว่าตอม่อสะพานที่สร้างเสร็จมีความสูงเกินไป ทำให้**ไม่สามารถนำไม้พื้นสะพานเดิมมาวางพาดได้** และพบว่าฐานรากขุดลึกเพียง 0.60-0.70 เมตร ทั้งที่แบบกำหนดไว้ไม่น้อยกว่า 2.50 เมตร

4.  **การเรียกค่าเสียหาย:** เทศบาลฯ แต่งตั้งคณะกรรมการสอบข้อเท็จจริง และมีคำสั่งให้นายอนุชาชดใช้ค่าเสียหาย 15,400 บาท (10% ของความเสียหาย 154,000 บาท) โดยเห็นว่านายอนุชา "มีเหตุน่าจะรู้" ถึงปัญหาและปฏิบัติหน้าที่โดยประมาทเลินเล่ออย่างร้ายแรง

## 💥 จุดแตกหัก (The Conflict)

### ฝ่ายนายอนุชา ปัญญา (ผู้ฟ้องคดี):
*   ปฏิบัติตามขั้นตอนระเบียบราชการทุกประการ
*   อนุมัติเบิกจ่ายตามรายงานของคณะกรรมการและเจ้าหน้าที่ทุกฝ่ายที่รับรองว่างานถูกต้อง
*   **ไม่เคยได้รับรายงาน**จากผู้ควบคุมงานหรือคณะกรรมการตรวจการจ้างว่ามีปัญหาใดๆ
*   ไม่มีหน้าที่โดยตรงในการควบคุมตรวจสอบงานก่อสร้างในพื้นที่ (เป็นหน้าที่ของผู้ควบคุมงานและคณะกรรมการตรวจการจ้าง)
*   การที่ "ได้ยินมา" ว่ามีการขอแก้ไขแบบแปลน เป็นเพียงข้อมูลบอกผ่านไม่เป็นทางการ ไม่ได้หมายความว่าทราบถึงปัญหา

### ฝ่ายเทศบาลตำบลบ้านแปะ (ผู้ถูกฟ้องคดี):
*   นายอนุชาในฐานะผู้บังคับบัญชาสูงสุด มีหน้าที่ควบคุมดูแลการปฏิบัติงานของเจ้าหน้าที่
*   มี**"เหตุน่าจะรู้"** ถึงปัญหา เพราะได้รับทราบว่ามีการขอแก้ไขแบบแปลนระหว่างดำเนินการ
*   ฎีกาเบิกจ่ายมีภาพถ่ายตอม่อสะพานประกอบ หากตรวจสอบอย่างรอบคอบจะเห็นว่าสูงเกินจริง
*   การที่ตอม่อสูงเกินและฐานรากไม่ได้มาตรฐาน ถือเป็นการกระทำโดยประมาทเลินเล่ออย่างร้ายแรง

## ⚖️ คำตัดสิน (The Ruling)

### 📋 ศาลปกครองชั้นต้น: **เพิกถอนคำสั่ง** (นายอนุชาไม่ต้องรับผิด)

ศาลปกครองชั้นต้นพิจารณาแล้วเห็นว่า:

1.  **การอนุมัติตามระเบียบ:** นายอนุชาอนุมัติเบิกจ่ายโดยพิจารณาจากรายงานของคณะกรรมการตรวจการจ้าง หัวหน้าพัสดุ หัวหน้าการคลัง และปลัด อบต. ซึ่งทุกฝ่ายรายงานว่างานถูกต้องตามสัญญา

2.  **ขอบเขตหน้าที่:** ระเบียบกระทรวงมหาดไทยว่าด้วยการพัสดุฯ **ไม่ได้กำหนดให้นายกฯ มีหน้าที่ต้องควบคุม ตรวจสอบ หรือทักท้วงการจ้างโดยตรง** หน้าที่ดังกล่าวเป็นของผู้ควบคุมงานและคณะกรรมการตรวจการจ้าง

3.  **ไม่ถือเป็นประมาทเลินเล่ออย่างร้ายแรง:** เมื่อไม่ปรากฏว่าคณะกรรมการตรวจการจ้างได้รายงานปัญหาใดๆ ให้ทราบ การที่นายอนุชาไม่อาจทราบถึงลักษณะที่แท้จริงของตอม่อจึงเป็น**เหตุสุดวิสัย** การอนุมัติเบิกจ่ายจึงเป็นการปฏิบัติตามขั้นตอนและระเบียบแล้ว

**ศาลปกครองชั้นต้นจึงพิพากษาเพิกถอนคำสั่งของเทศบาล**

### 🏛️ ศาลปกครองสูงสุด: **พิพากษายืน** (ยืนยันว่านายอนุชาไม่ต้องรับผิด)

ศาลปกครองสูงสุดพิจารณาแล้ว**เห็นพ้องด้วยกับศาลชั้นต้น** โดยให้เหตุผลเพิ่มเติมที่สำคัญว่า:

1.  **ลักษณะสัญญา:** สัญญาเลขที่ 1/2552 เป็นการก่อสร้าง**เฉพาะตอม่อสะพานเท่านั้น** ไม่ใช่สะพานทั้งหมด เนื่องจากงบประมาณไม่พอ จึงจะมีการก่อสร้างเพิ่มเติมในภายหลัง

2.  **ไม่อาจคาดเห็นได้:** เมื่อการส่งมอบงานเป็นเพียง "ตอม่อ" ยังไม่สำเร็จเป็นสะพานสมบูรณ์ **นายอนุชาจึงไม่อาจคาดเห็นได้** ว่าตอม่อที่สร้างแล้วจะใช้การไม่ได้ในภายหลัง จะรู้ได้ก็ต่อเมื่อมีการก่อสร้างให้แล้วเสร็จเป็นสะพานเท่านั้น

3.  **ข้อมูล "ได้ยินมา" ไม่ใช่การทราบอย่างเป็นทางการ:** การที่นายอนุชา "ได้ยินมา" ว่ามีการขอแก้ไขแบบแปลน แต่ไม่มีการเสนอเรื่องอย่างเป็นทางการให้ทราบ ไม่ถือว่าเป็นการ "ควรจะได้รู้" ตามที่เทศบาลฯ อ้าง

4.  **ไม่สามารถตรวจสอบด้วยสายตาทั่วไปได้:** แม้จะมีภาพถ่ายประกอบฎีกา แต่การพิจารณาด้วยสายตาของบุคคลทั่วไปหรือผู้บริหารที่**ไม่มีความรู้ทางวิชาการช่างโดยเฉพาะ** ไม่อาจทราบได้ว่าตอม่อมีความสูงเกินไป

5.  **ไม่มีรายงานปัญหา:** ไม่ปรากฏว่าผู้ควบคุมงานหรือคณะกรรมการตรวจการจ้างมีการรายงานต่อนายอนุชาว่า:
    *   การก่อสร้างไม่ถูกต้องตามแบบ
    *   มีการทักท้วงเรื่องการก่อสร้างผิดแบบแปลน
    *   มีการเสนอขอแก้ไขแบบแปลนอย่างเป็นทางการ

**ศาลปกครองสูงสุดจึงพิพากษายืนตามศาลชั้นต้น เพิกถอนคำสั่งให้ชดใช้ค่าเสียหาย**

## 📝 บทสรุปและข้อคิด (Key Takeaways)

คดีนี้เป็นบทเรียนสำคัญที่แสดงให้เห็นว่า **ผู้บริหารไม่จำเป็นต้องรับผิดในทุกกรณี** หากได้ปฏิบัติหน้าที่ตามระเบียบและพึ่งพารายงานของเจ้าหน้าที่ที่รับผิดชอบอย่างถูกต้อง

### สำหรับผู้บริหาร (For Executives)

1.  **การพึ่งพารายงานของเจ้าหน้าที่เป็นสิ่งที่ยอมรับได้:** เมื่อคณะกรรมการตรวจการจ้างและเจ้าหน้าที่ที่เกี่ยวข้องรายงานว่างานเสร็จเรียบร้อยตามสัญญา ผู้บริหารสามารถพึ่งพารายงานดังกล่าวในการอนุมัติเบิกจ่ายได้

2.  **ไม่มีหน้าที่ต้องเป็นผู้เชี่ยวชาญทุกด้าน:** ผู้บริหารไม่จำเป็นต้องมีความรู้ทางวิศวกรรมหรือเทคนิคเฉพาะทาง การตรวจสอบทางเทคนิคเป็นหน้าที่ของผู้ควบคุมงานและคณะกรรมการที่ได้รับการแต่งตั้ง

3.  **ข้อมูล "ได้ยินมา" ไม่เพียงพอ:** การได้รับข้อมูลแบบบอกผ่านหรือไม่เป็นทางการไม่ถือว่าเป็น "เหตุน่าจะรู้" ที่จะทำให้ต้องรับผิด ต้องมีการรายงานอย่างเป็นทางการเท่านั้น

4.  **ปฏิบัติตามระเบียบอย่างครบถ้วน:** ตรวจสอบให้แน่ใจว่า:
    *   ฎีกามีเอกสารประกอบครบถ้วน
    *   มีลายเซ็นต์ของผู้ที่เกี่ยวข้องตามลำดับชั้น
    *   มีรายงานจากคณะกรรมการตรวจการจ้างและผู้ควบคุมงาน
    *   หากรายงานระบุว่า "ถูกต้องตามสัญญา" การอนุมัติจึงชอบด้วยกฎหมาย

### สำหรับผู้ควบคุมงานและคณะกรรมการตรวจการจ้าง (For Project Officers)

1.  **ความรับผิดชอบหลักอยู่ที่ท่าน:** คณะกรรมการตรวจการจ้างและผู้ควบคุมงานเป็นผู้ที่มีหน้าที่โดยตรงในการตรวจสอบงานให้เป็นไปตามแบบและสัญญา **ท่านไม่สามารถปัดความรับผิดชอบไปให้ผู้บริหารได้**

2.  **รายงานปัญหาทันที:** หากพบว่างานก่อสร้างมีปัญหา ไม่ตรงแบบ หรืออาจไม่บรรลุวัตถุประสงค์ ต้อง**รายงานผู้บริหารทันทีอย่างเป็นทางการ** ไม่ใช่แค่ "บอกผ่าน"

3.  **อย่ารายงานเท็จ:** การรายงานว่า "งานถูกต้องตามสัญญา" ทั้งที่รู้ว่าไม่ถูกต้อง อาจทำให้ท่านต้องรับผิดชดใช้ค่าเสียหายแทน

### สำหรับผู้รับจ้าง (For Contractors)

1.  **แจ้งปัญหาอย่างเป็นทางการ:** หากพบข้อจำกัดหรือปัญหาที่อาจทำให้โครงการไม่บรรลุวัตถุประสงค์ ต้องแจ้งหน่วยงานเจ้าของโครงการและขออนุมัติแก้ไขแบบเป็นลายลักษณ์อักษร

2.  **เอกสารเป็นหลักฐานสำคัญ:** ทุกการสื่อสาร การขอแก้ไข หรือการรายงานปัญหา ควรทำเป็นหนังสือเป็นหลักฐาน ไม่ใช่แค่บอกปากเปล่า
